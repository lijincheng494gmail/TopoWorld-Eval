# Typesetting components

The public main report uses `source/main/topoworld_report.sty`, a presentation-only adaptation of the article typography and layout in the [computer-vision author kit](https://media.eventhosts.cc/Conferences/CVPR2027/author-kit-CVPR2027-v1-latex.zip). It removes review-specific options, watermarks, line numbers, and anonymous author handling. This attribution identifies the source of typesetting code and makes no venue-status claim.

`ieeenat_fullname.bst` is retained with its original embedded comments and attribution. The supplementary report uses standard installed LaTeX packages and the `plainnat` bibliography style. Third-party components retain their applicable rights; no project-wide license is imposed on them.
