# Public research release 1.0.0

This release provides the TopoWorld-Eval technical report, supplementary report, editable sources, frozen 2.2.1 evaluation code, synthetic examples, and a complete offline reproducibility archive. Authors: Jincheng Li and Yuxuan Li.

The public derivative preserves the scientific scoring logic, exported model responses, references, image pixels, and historical results. It updates distribution documentation, source attribution, rights notices, and package verification. Its source snapshot is identified by SHA-256 in the archive.

The retained study has 14 buildings, 42 drawing pages, 688 GPT stages and 42 Qwen submissions. The first public-package macOS replay matches all 730 frozen scientific signatures and both principal table objects. Independent Linux x86-64/Python 3.13.18 validation also matches 730/730 and both table objects; its GitHub run and receipt are linked in the reproducibility documentation. These are offline re-scoring results, not new model experiments.

Large assets are Release attachments, outside normal Git history. Use docs/release.json and the download script to verify the archive. Third-party notices and the project rights statement are included; no new project-wide reuse license is implied.
