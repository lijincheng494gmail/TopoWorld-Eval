# Evaluation protocol

## Scientific scope

The unit is a supported architectural target fragment viewed across assigned drawing pages. References constrain selected spatial relations and identity; they are not a complete measured 3D model.

The represented world is W = (O, G, α, R, P). O contains physical instances and parts; G contains occupied/free regions in a common frame; α binds observations to instances; R contains typed relations; P records sources and support dependencies. Unmeasured dimensions can be marked as hypothetical completions.

## Inputs and independent routes

R returns direct relation answers. A constructs from the same core visual evidence. B additionally receives correct determinate relation values, without reference coordinates. Each route uses an independent context. N2 uses neutral point/class anchors; CS1 adds object-unit hints. Historical semantic-locator v1 and N2 reuse the same 12 buildings and are not combined as independent building samples.

Codex tasks may read assigned files, display images, make crops from the same pixels, and save their first output. They may not consult references, other results, solvers, or evaluator feedback. This is an instruction-level boundary rather than an enforced operating-system isolation boundary. Actual departures remain recorded. Qwen receives tool-free API image requests; its R request also includes a generic Schema absent from GPT R. Product effort controls are not equal compute budgets.

## Fixed scoring

Evaluator 2.2.1 preserves original parser, Schema, geometry, condition-specific scorers, query labels, and response limits. First outputs have a 42,000-character and 60-entity envelope. Missing, malformed, invalid, and content-incorrect outputs remain distinct. No parser repairs are applied.

Relation accuracy uses all allocated determinate obligations. A second paired analysis includes obligations only when both compared outputs are contract-valid. These denominators answer different questions.

Registered geometry covers registered target roles and their dependency closure. All-declared geometry additionally checks submitted structures outside that closure. A joint success requires valid representation, required coverage, correct determinate relations, and geometry PASS at the stated scope. UNKNOWN or NOT_EVALUABLE is not counted as geometry PASS.

Given-point localization checks image-source bindings and approximate reference boxes at IoU ≥ 0.25. It does not measure unrestricted object discovery. Geometry verifies declared material and interfaces, not full human movement or construction safety.

## Evidence revision

E0 uses initial permitted plans. E1 adds a section supporting a measured height. E2 withdraws it and revises the world. F2 starts fresh under the same remaining evidence. Evaluation separates explicit knowledge/source state from retained relation readouts. It does not measure hidden-memory deletion or an equal-cost incremental inference advantage.

## Known measurement boundary

Evaluator 2.2.1 has a documented slab-equivalence limitation. Equivalent material decompositions can receive different evaluability labels. Frozen main scores have not been selectively changed.
